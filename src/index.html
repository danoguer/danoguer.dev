01

Sentinel

AI-Driven SRE Context Engine & Daemon

A native Go background daemon that continuously monitors Linux host telemetry, extracts diagnostic snapshots upon failure, and interfaces with the Gemini API to provide actionable root-cause analysis.

Why I built it

“I was tired of copying terminal output into an AI for blind advice. An LLM cannot reason without live context: process trees, socket health, and telemetry must precede inference.”

01 · Host Telemetry Continuous scraping of Linux kernel metrics via Prometheus and structured system logs from journald as an immutable evidence layer.
Key Engineering Decisions
+
UNIX Sockets & Background Daemon: Eliminates CLI cold-start latency and buffers host telemetry continuously in memory rather than reading disks on demand.
+
Evidence-First Bounded Payloads: Sanitizes, deduplicates, and structures host telemetry within safe token limits before querying the Gemini API.

02

CloudForge

Automated Cloud Infrastructure & IaC Pipeline

A production-style AWS environment built to demonstrate reproducible infrastructure, automated configuration management, and containerized deployment from a clean account.

Why I built it

“Inception solved local multi-container runtimes, but cloud setup remained fragile and manual. I wanted one-command reproducibility from bare AWS accounts to live production.”

01 · Terraform Provisioning Declarative VPC, isolated subnets, Security Groups, EC2 instances, and least-privilege IAM roles with remote S3 state locking.
Key Engineering Decisions
+
Strict Layer Decoupling: Terraform exclusively provisions cloud primitives; Ansible exclusively owns OS configuration, hardening, and runtime deployment.
+
Segmented Bridge Networks: Database and internal application services never expose public host ports; Nginx acts as the hardened ingress proxy.
AWS Terraform Ansible Docker GitHub Actions

[ infrastructure as product ]

This portfolio is not hosted on a traditional web server. It is a serverless AWS architecture designed around immutable deployments, private origins, short-lived OIDC credentials, and edge security.

Deployment & Identity

Every deployment is triggered through GitHub Actions and authenticated against AWS using OpenID Connect (OIDC). Zero long-lived AWS keys stored in secrets.

Origin Isolation

The S3 bucket remains private and blocked to the public internet. CloudFront reaches it strictly via Origin Access Control (OAC).

Edge Hardening

Lambda@Edge applies strict Content-Security-Policy and security headers at the edge, while Route 53 and ACM ensure HTTPS delivery.
